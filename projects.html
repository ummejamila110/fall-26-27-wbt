Face Detected Attendance System

Project Description

Developed a face recognition-based attendance management system using ASP.NET Core MVC. The system captures student images through a camera, identifies registered students, and records attendance automatically. It also includes student registration, student list management, and attendance history features to make attendance tracking easier and more efficient.

Tech Stack

Frontend: HTML, CSS, JavaScript, Bootstrap
Backend: C#, ASP.NET Core MVC
Database: SQL Server, Entity Framework Core
Face Recognition: OpenCV, ONNX
Tools: Visual Studio, Git, GitHu

Super Market Management System

Project Description

Developed a desktop-based Supermarket Management System using Java in IntelliJ IDEA. The application helps manage products, inventory, sales, billing, and customer transactions efficiently. It simplifies daily supermarket operations and improves accuracy in managing sales and stock records.

Tech Stack

Programming Language: Java
IDE: IntelliJ IDEA
GUI: Java Swing / JavaFX
Database: MySQL
Concepts: Object-Oriented Programming (OOP)
Tools: Git, GitHub

Smart Hostel Management System

Project Description

Developed a web-based Smart Hostel Management System using ASP.NET Core MVC. The system helps manage student information, room allocation, hostel facilities, and payment records. It simplifies hostel administration, improves data management, and makes daily hostel operations more efficient.

Tech Stack

Frontend: HTML, CSS, JavaScript, Bootstrap
Backend: C#, ASP.NET Core MVC
Database: SQL Server, Entity Framework Core
Face Recognition: OpenCV, ONNX
